# AERO DECK 1.1.0

Rilis ini memperluas AERO DECK sebagai soundboard/video deck gratis untuk
Windows, tetap menggunakan keyboard dan tanpa memerlukan perangkat tambahan.

## Highlight

- Buat beberapa deck dan aktifkan hanya hotkey dari deck yang sedang dipilih.
- Susun ulang pad dengan drag-and-drop.
- Pilih mode playback `exclusive`, `restart`, `toggle`, atau `overlap`.
- Hentikan seluruh media dari aplikasi mana pun dengan hotkey **Stop All**.
- Jalankan aplikasi bersama Windows dan mulai dalam keadaan diminimalkan.
- Export/import seluruh deck, pad, dan pengaturan sebagai backup JSON.
- Kelola pengaturan, buka lokasi data, lihat versi, dan cek update secara manual
  dari Settings/About.

## Upgrade dari 1.0.0

Library lama dimigrasikan otomatis ke deck awal. File media asli tidak disalin,
diubah, atau dihapus. Setelah aplikasi berhasil dibuka, buat export backup
sebelum melakukan perubahan besar.

Hotkey pad kini hanya aktif untuk deck yang dipilih. Hotkey **Stop All** default
adalah `Ctrl+Alt+F12`; ubah dari Settings jika kombinasi tersebut dipakai
Windows atau aplikasi lain.

## Backup dan privasi

Backup menyimpan konfigurasi serta path media, bukan file audio/video. Path dapat
memuat nama pengguna atau struktur folder, jadi jangan unggah backup ke issue
publik. Import mengganti library saat ini setelah konfirmasi.

Pengecekan update tidak berjalan otomatis. AERO DECK hanya menghubungi GitHub
Releases ketika pengguna menekan **Cek update**, dan tidak mengirim media atau
isi library.

## Unduhan dan signature

Unduh `AERO-DECK-Setup-1.1.0.exe` dari Assets pada release resmi. Installer ini
ditujukan untuk Windows 10/11 x64.

> Installer 1.1.0 belum ditandatangani dengan sertifikat code signing. Windows
> dapat menampilkan **Unknown publisher**. Pastikan unduhan berasal dari
> repository `copszeo/AERO-DECK` dan cocokkan SHA-256 dengan
> `SHA256SUMS.txt`.

AERO DECK tidak berafiliasi atau di-endorse oleh Elgato maupun Corsair. Proyek
ini merupakan alternatif perangkat lunak untuk kebutuhan soundboard/video, bukan
pengganti seluruh fungsi perangkat keras atau ekosistem Stream Deck.
