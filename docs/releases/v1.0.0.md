# AERO DECK 1.0.0

Rilis publik pertama AERO DECK: soundboard dan video deck Windows dengan global
hotkey.

## Highlight

- Tambahkan audio atau video sebagai media pad.
- Gunakan A–Z, 0–9, F1–F12, atau kombinasi modifier sebagai global hotkey.
- Putar media ketika dashboard diminimalkan atau berada di system tray.
- Tampilkan video pada jendela player terpisah tanpa mengambil fokus aplikasi
  yang sedang digunakan.
- Atur warna, volume, loop, pencarian, dan status playback per pad.
- Konfigurasi disimpan secara lokal dan file media asli tidak diubah.

## Unduhan

Unduh `AERO-DECK-Setup-1.0.0.exe` dari bagian Assets di bawah. Installer ini
ditujukan untuk Windows 10/11 x64.

> Build 1.0.0 belum ditandatangani sertifikat komersial. Windows SmartScreen
> dapat menampilkan **Unknown publisher**. Pastikan unduhan berasal dari
> repository `copszeo/AERO-DECK` dan cocokkan SHA-256 dengan
> `SHA256SUMS.txt`.
