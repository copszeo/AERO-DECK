# AERO DECK 1.2.0

Versi 1.2.0 membuat AERO DECK lebih dari soundboard. Sekarang satu tombol dapat
memutar klip, membuka aplikasi, mengirim shortcut, mengetik pesan, berpindah
deck, atau menjalankan beberapa langkah—tetap dari keyboard yang sudah Anda
punya dan tetap bekerja saat dashboard berada di latar belakang.

## Yang baru

- **Buka** aplikasi, file, atau folder lokal.
- **Tutup aplikasi** berdasarkan executable yang cocok persis, dengan opsi
  paksa bila penutupan normal tidak memungkinkan.
- Buka **website atau URI aplikasi yang didukung**, kirim **hotkey**, ketik **teks + Enter**, dan
  jalankan kontrol multimedia Windows.
- Pindah ke deck lain sebagai bagian dari action.
- Masukkan audio/video yang sudah ada sebagai langkah automasi.
- Beri setiap action pad nama, warna, dan hotkey global seperti media pad.

## Builder automasi

Tidak perlu menulis JSON. Builder visual menyediakan empat pola:

- **Sequence** menjalankan langkah satu per satu.
- **Bersamaan** memulai hingga delapan langkah secara paralel.
- **Random** memilih satu pilihan setiap kali dipicu.
- **Toggle** bergantian antara dua keadaan.

Tambahkan **Delay** untuk mengatur jeda dan gabungkan langkah media, open/close,
website, hotkey, teks, multimedia, atau pindah deck. Stop All juga membatalkan
langkah action yang masih berjalan, tetapi tidak mengurungkan pekerjaan OS yang
sudah selesai. Sequence memulai langkah berikutnya setelah permintaan media
dikirim; ia tidak menunggu durasi klip hingga selesai.

## Upgrade dari 1.1.0

Library lama dimigrasikan otomatis ke schema v3. Media pad, deck, hotkey,
playback mode, dan file asli tidak diubah. Referensi action diperiksa agar media
atau deck yang masih dipakai automasi tidak terhapus tanpa sengaja.

Setelah pertama kali membuka 1.2.0, export backup baru sebelum membuat automasi
besar. Backup versi ini mencakup action pad dan semua langkahnya.

## Catatan penting tentang action

Action **Kirim hotkey** dan **Ketik teks** bekerja melalui simulasi keyboard
Windows. Input masuk ke jendela yang sedang fokus dan karakter mengikuti layout
keyboard aktif. Fokuskan aplikasi tujuan sebelum menekan pad.

Penutupan normal memberi aplikasi kesempatan untuk menangani penyimpanan. Opsi
**paksa** dapat menghentikan proses dan menghilangkan pekerjaan yang belum
disimpan; gunakan hanya jika memang diperlukan.

Backup action harus diperlakukan seperti macro atau script lokal. Import tidak
langsung menjalankan action, tetapi action hasil import dapat membuka/menutup
aplikasi, membuka URL, atau mengetik teks ketika kemudian dipicu. Impor hanya
file buatan sendiri atau dari sumber yang benar-benar tepercaya.

## Cakupan yang jujur

AERO DECK belum memiliki plugin/Marketplace, integrasi native OBS, pages atau
folders, key logic double-press/press-and-hold, companion mobile, maupun dukungan
hardware Stream Deck. Action input, multimedia, dan close tertentu ditujukan
untuk Windows dan tidak dijanjikan bekerja lintas platform.

AERO DECK tetap gratis, open-source, dan berlisensi MIT. Proyek ini dikembangkan
secara independen dan tidak berafiliasi, disponsori, atau didukung oleh Elgato,
Corsair, maupun pihak lain.

## Unduhan dan signature

Unduh `AERO-DECK-Setup-1.2.0.exe` hanya dari Assets pada release resmi. Installer
ditujukan untuk Windows 10/11 x64.

> Installer publik belum ditandatangani dengan sertifikat code signing. Windows
> dapat menampilkan **Unknown publisher**. Pastikan unduhan berasal dari
> repository `copszeo/AERO-DECK` dan cocokkan SHA-256 dengan
> `SHA256SUMS.txt`.
